# Initial configuration security

Complete initial configuration before exposing the panel publicly. The first account created receives administrator permissions.

The public self-hosted distribution is in preparation. Installation commands will be published after validation on a clean machine.

# Segurança da configuração inicial

Conclua a configuração inicial antes de expor o painel publicamente. A primeira conta criada recebe permissões de administrador.

A distribuição pública self-hosted está em preparação. Os comandos de instalação serão publicados após validação em máquina limpa.
